The "RIDF_CodeGenerator.R" is an automated workflow used to generate a rain intensity duration and frequency (RIDF) table. It reads daily rainfall observation and produces rainfall events of different intensities and frequency, including 2-year, 5-year, 10-year, 25-year, 50-year, and 100-year rain return periods.
End users of the file are required to modify line 10. The "input_file" variable should contain the local path directory of the daily rainfall observation in CSV file format. In conjunction, specific data formatting is required for the code to read the file and generate the RIDF output correctly. Kindly peruse the "LaucalaBay_Rainfall.csv" file to inspect the prescribed CSV input data format.
The code also produces a line graph visualization of the RIDF values, and automatically saves the figure into your local directory. To unlock this feature of the code, you need to modify line 99 and specify the local directory you wish to save the .png file of the line graph.
The current structure of this workflow was developed using R version 2023.3.0.386 and uses RStudio as the main Integrated Development Environment. A more updated version of the R language will read the code perfectly. Future development and debugging of the code is fully supported by our team at UP Resilience Institute.
